# Server Manager

## Overview
Server Manager is a built-in Windows Server administration tool used to manage and monitor Windows Server systems. It provides administrators with a centralized interface to install server roles, manage features, view server status, and perform administrative tasks.

## Purpose
Server Manager is commonly used by system administrators to configure and maintain Windows Server environments. In an enterprise environment, administrators use Server Manager to deploy services such as Active Directory Domain Services (AD DS), DNS, DHCP, and File Services.

## Lab Usage
In this lab, Server Manager was used to prepare the Windows Server 2025 virtual machine for Active Directory deployment.

Tasks performed using Server Manager:

- Reviewed server information and status
- Accessed the Add Roles and Features wizard
- Installed the Active Directory Domain Services role
- Verified installed server roles

## Importance in a Real-World Environment
Server Manager allows administrators to manage Windows Server roles and features without needing to use command-line tools. It provides visibility into server health and simplifies the deployment of important infrastructure services.
