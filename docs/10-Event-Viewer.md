## Important Security Event IDs

| Event ID | Description |  

| 4624 | Successful logon |  
| 4625 | Failed logon |  
| 4720 | User account created |  
| 4726 | User account deleted |  
| 4732 | User added to security-enabled local group |

## Cybersecurity Importance
Security logs are important because they provide visibility into activity occurring on a system.

Security professionals use logs to:

- Detect suspicious login attempts
- Investigate account compromise
- Identify unauthorized changes
- Support incident response investigations

A SOC analyst may review these events in a SIEM platform such as Splunk or Microsoft Sentinel to identify threats across an organization.
